# 🌿 Greenden - Responsive Plant E-Commerce Concept

A modern, highly creative, and fully responsive multi-page landing website developed as part of a **MERN Stack Development** track. This project focuses on mastering clean semantic HTML structure, styling with the utility-first **Tailwind CSS framework**, and implementing interactive client-side logic using pure **Vanilla JavaScript**.

## 📂 Website Architecture & Key Pages
The application features a modular structure unified by a shared, modern **Glassmorphic navigation system**:

### 1. 🏠 Home Page (`index.html`)
* **Creative Split-Screen Hero:** Features strong typography hooks paired with vibrant, atmospheric high-resolution imagery.
* **Value Proposition Matrix:** A grid section showcasing modern infrastructure features like Premium Genetics, Secure Freight Insulation, and Lifetime Care Support.
* **Interactive Newsletter:** A styled subscription capture panel built to match clean layout specifications.

### 2. 🛒 Products Page (`products.html`)
* **Dynamic Bento Grid Layout:** Showcases premium plant variations (e.g., *Monstera Deliciosa*, *Snake Plant Zeylanica*, *Calathea Medallion*) equipped with interactive state transitions.
* **Client-Side Live Cart System:** 
  * Features a slide-over flyout basket drawer.
  * Real-time item count updates on navigation badges.
  * Live-calculating price summary counters.

### 3. 📬 Contact Page (`contact.html`)
* **Split Side-by-Side Panel Layout:** Pairs essential studio location indicators alongside an interactive, beautifully structured user message submission form.

## 🛠️ Technical Stack & Framework Features
* **HTML5:** Semantic architecture layout markers ensuring standard web accessibility practices.
* **Tailwind CSS (via Play CDN):** Extensively leverages flexible grid layouts (`grid-cols-1 md:grid-cols-2 lg:grid-cols-3`), custom spacing increments, color extensions, and responsive breakpoints (`sm:`, `md:`, `lg:`).
* **Vanilla JavaScript (ES6+):** Utilizes event listener matrices, array state manipulation logic, dynamic DOM generation via template strings, and toggle classes for mobile responsive layout morphing.

---

## 🧑‍💻 Technical Key Highlights (What I Mastered)
1. **Utility-First Layout Design:** Discarded heavy external media query stylesheets in favor of inline, flexible Tailwind breakpoint rules that adapt seamlessly across devices.
2. **Dynamic UI Rendering:** Transferred product datasets through structural `data-*` DOM variables into global array variables—laying a foundation for modern React state patterns.
3. **Interactive Components:** Programmed an interactive, sliding drawer mobile viewport drawer menu and built a client-side product basket simulation from scratch.
